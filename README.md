# 李相杰 · 小李的项目作品集

静态作品集，包含创意活动项目、设计类项目与线下活动策划。

所有图片和标题字体都随仓库提供，不依赖 Google Fonts、数据库或构建步骤。首页原版矢量字形、逐字浮动与碰撞、分类选中暂停和作品弹窗均保留。

## 发布

推送到 `main` 后，通过 `.github/workflows/pages.yml` 部署 GitHub Pages。仓库 Settings → Pages 的发布源应设置为 GitHub Actions。

预期地址（部署成功后生效）：https://napan2004.github.io/22/

GitHub Pages 不是香港节点托管，不能保证中国大陆各网络的访问稳定性。后续可用本仓库的相同静态文件迁移到香港主机。
